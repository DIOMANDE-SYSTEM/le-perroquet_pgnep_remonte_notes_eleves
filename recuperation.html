🛟 Récupération des données — Le Perroquet

🛑 Avant tout : n'ouvrez plus l'application (ni la Plateforme IEPP) et n'effacez rien dans le navigateur tant que vous n'avez pas téléchargé les sauvegardes de la section 2. Si Firebase refuse les écritures en attente, le navigateur peut les supprimer définitivement.

Cet outil ne modifie rien tant que vous ne cliquez pas sur un bouton rouge « Renvoyer vers le cloud ». Il cherche vos élèves, notes et comptes à trois endroits : le cloud (Firebase), le cache hors ligne du navigateur et le stockage local.
⚠️ Pour voir les données de l'appareil, ouvrez cette page depuis le même site que l'application (même adresse, même navigateur) et fermez les autres onglets de l'application. N'effacez pas les données du navigateur.

Rien n'est modifié ni envoyé. Le fichier SQL permet de charger directement ces données dans Supabase (SQL Editor).
