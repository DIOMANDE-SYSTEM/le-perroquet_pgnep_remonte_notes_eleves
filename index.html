🦜 Présentation de Le Perroquet

Le Perroquet (PGNEP v3.0) est une plateforme numérique pour la gestion des notes des élèves du cycle primaire en Côte d'Ivoire.

📊 Calcul automatique des moyennes selon les barèmes officiels
🏅 Rang de chaque élève dans sa classe
📄 Bulletins de notes imprimables en 1 clic
🎓 DFA calculée automatiquement
📋 Liste de classe par ordre alpha ou rang
📈 Statistiques par sexe et composition
🔒 8 profils sécurisés avec cloisonnement
📱 PC, navigateur web et Android
Hiérarchie : Instituteur → Directeur → CPPP → Correspondant IEPP → Coordinateur DRENAET → Administrateur
Chaque utilisateur ne voit que les données de son périmètre.

💻 Installation et accès

🌐 Version navigateur web (recommandée)
1. Télécharger le fichier PGNEP_v3.html
2. Double-cliquer pour l'ouvrir dans Chrome ou Edge
3. Marquer la page en favori pour un accès rapide
🖥 Version Windows (.exe)
1. Installer Node.js depuis nodejs.org
2. Dézipper LePerroquet_Windows_Electron.zip
3. Ouvrir un terminal → npm install
4. Taper npm run build-win → le .exe se crée dans dist/
📱 Version Android (.apk)
1. Installer Android Studio depuis developer.android.com
2. Dézipper LePerroquet_Android_Studio.zip
3. Ouvrir le dossier android/ dans Android Studio
4. Build → Build APK(s) → installer l'APK sur le téléphone
✈️ Fonctionne entièrement hors connexion internet. Les données sont sauvegardées automatiquement dans le navigateur.

👦 Gestion des élèves

➕ Ajouter un élève manuellement
1. Cliquer sur + Ajouter (bouton en haut)
2. Remplir : Nom, Prénoms, Sexe, Classe, École (et optionnellement Matricule, Date de naissance, Lieu)
3. Cliquer sur Enregistrer
📥 Importer en masse (Excel ou CSV)
1. Aller dans Export / Synchro → section Import
2. Glisser votre fichier .xlsx, .xlsm ou .csv
3. Vérifier l'aperçu des élèves détectés
4. Cliquer sur 💾 Enregistrer dans la base
🎓 Passage en classe supérieure
1. Cliquer sur 👁 à côté de l'élève
2. Cliquer sur 🎓 Passage en classe supérieure
3. Confirmer — les élèves de CM2 sont archivés fin de cycle
💡 Le matricule est généré automatiquement si laissé vide. Les doublons (même matricule) sont ignorés à l'import.

Procédure de saisie
1. Aller dans Saisie des notes
2. Sélectionner l'élève
3. Sélectionner le type d'évaluation
4. Saisir les notes (la moyenne se calcule en temps réel)
5. Cliquer sur 💾 Enregistrer les notes
📌 Code 501 = Absent / Abandon. La matière est exclue du calcul. Affichée ABS sur le bulletin.
🚫 L'Examen Blanc n'apparaît que pour les élèves de CM2. Les Compositions 3 et 4 n'apparaissent pas pour le CM2.

📄 Bulletins de notes

Générer et imprimer un bulletin
1. Cliquer sur Bulletins de notes
2. Sélectionner l'élève
3. Sélectionner l'évaluation (ou laisser vide pour toutes)
4. Cliquer sur 🖨 Imprimer
Le bulletin contient : en-tête école/IEPP/DRENAET, informations élève, tableau des matières, total, moyenne, rang dans la classe, mention, résultat DFA, espaces de signature.

🎓 DFA — Décision de Fin d'Année

La DFA est calculée automatiquement — ce n'est pas une évaluation à saisir.
📐 Formule CP1 → CM1
DFA = [ (Moy1 + Moy2 + Moy3) + Moy4 × 2 ] / 5
Évaluations : Composition 1, 2, 3 et 4
📐 Formule CM2
DFA = [ (Moy1 + Moy2 + MoyEB1) + MoyEB2 × 2 ] / 5
Évaluations : Composition 1, Composition 2, Examen Blanc 1, Examen Blanc 2
(Le CM2 ne fait pas de Composition 3 et 4)
RésultatCondition
✅ DFA AdmisMoyenne DFA ≥ 10/20
❌ DFA ÉchecMoyenne DFA < 10/20
✅ DFA Admis — À archiverCM2, DFA ≥ 10 → fin de cycle
⏳ IncompletToutes les compositions requises non saisies

❓ Questions fréquentes (FAQ)

Mes données ont disparu après avoir effacé l'historique.
Les données sont dans le localStorage du navigateur. Effacer l'historique les supprime. Faites des exports JSON régulièrement.
Je ne vois pas les élèves des autres classes.
C'est normal. Chaque utilisateur voit uniquement son périmètre : un instituteur voit sa classe, un directeur son école, etc.
L'option Examen Blanc n'apparaît pas.
Les examens blancs sont réservés aux élèves de CM2. Vérifiez que l'élève sélectionné est bien en CM2.
La DFA affiche « Incomplet ».
Pour CP1-CM1 : les 4 compositions doivent être saisies. Pour CM2 : Composition 1, 2, Examen Blanc 1 et 2 requis.
Je ne peux pas créer de compte utilisateur.
La création de comptes est réservée aux administrateurs (admin et diomande).
Mon compte est bloqué.
Après 5 tentatives échouées, le compte est bloqué 15 minutes. Attendez puis réessayez.
Mon fichier Excel ne s'importe pas.
Vérifiez que le fichier contient une colonne nommée « nom ». Les formats .xlsx, .xlsm et .csv sont acceptés. Une connexion internet est nécessaire pour charger la bibliothèque Excel.
