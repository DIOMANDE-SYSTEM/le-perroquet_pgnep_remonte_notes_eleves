🚚 Migration Firebase → Supabase

Cette page copie toutes vos données de Firebase vers Supabase. Rien n'est supprimé ni modifié dans Firebase. Vous pouvez la relancer sans risque (les fiches existantes sont simplement mises à jour).

Avant de commencer : les règles Firestore doivent être publiées en lecture (allow read: if true) et le script supabase_schema.sql exécuté dans Supabase.
